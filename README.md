# 📊 Desain Web untuk Sains Data (Figma to Bootstrap/Tailwind)

Repository ini berisi materi dan panduan perkuliahan **Desain Web** untuk mahasiswa Sains Data berbasis _Project-Based Learning_. Perkuliahan difokuskan pada perancangan antarmuka visualisasi data (**Data Dashboard System**), diawali dari konsep UI/UX, perancangan di Figma, hingga implementasi _slicing_ antarmuka responsif dan interaktif menggunakan _CSS Framework_ dan JavaScript dasar.

---

## 📌 Format Perkuliahan (3 SKS / 150 Menit)

- **15–20 Menit:** Briefing Teori / Demo Singkat
- **100 Menit:** Hands-on Studio / Slicing Code / Asistensi Direct
- **30 Menit:** Review Progress & Checklist Output
