### Mengapa Format Ini Lebih Efektif Dibanding RPS Asli?

1. **RPS Asli:** Terlalu teoretis di awal (menghabiskan 5-6 minggu hanya untuk HTML/CSS Vanilla murni).
2. **Format README Baru:** Mengadopsi _workflow_ industri (Figma $\rightarrow$ Framework $\rightarrow$ JS Interaktif). Mahasiswa langsung menghasilkan _Data Dashboard_ fungsional tanpa membuang waktu terjebak pada kendala sintaksis CSS manual.
